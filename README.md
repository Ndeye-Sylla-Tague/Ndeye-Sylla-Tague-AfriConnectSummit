# AfriConnect Summit 
Projet : Site web vitrine d'une conférence tech panafricaine.  
Auteur : Ndeye Sylla Tague  
Promotion : L1 DSBD — ISI  

## 📖 Description

« AfriConnect Summit est le site vitrine complet d'une conférence tech annuelle panafricaine qui réunit développeurs, entrepreneurs et investisseurs du continent. Le site intègre les standards du web moderne : une typographie expressive, des animations sobres, un mode sombre, une navigation fluide et un code irréprochable. »

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique ('<header>', '<nav>', '<main>', '<section>', '<footer>')
- **CSS3** : Flexbox, CSS Grid, animations, transitions, variables CSS, responsive design via media queries
- **Bootstrap Icons** : Icônes vectorielles
- **Google Fonts** : Typographie personnalisée (titres et corps de texte)
- **JavaScript Vanilla** : Manipulation du DOM, gestion d'événements, `IntersectionObserver`, `localStorage`
- **Git & GitHub** : Versioning et déploiement via GitHub Pages

## ✨ Fonctionnalités principales

1. **Dark Mode / Light Mode** : Toggle dans la navbar, thème sauvegardé dans le `localStorage` et persistant entre les pages.
2. **Compteurs animés** : S'incrémentent au scroll via `IntersectionObserver`.
3. **Filtrage dynamique** : Filtrage des intervenants par thématique sans rechargement de page.
4. **Validation de formulaire** : Contrôle complet des champs (regex email, longueurs, formats) avec retours visuels.
5. **Navbar dynamique** : Changement de style et d'ombre au défilement, menu hamburger responsive.
6. **Bouton retour en haut** : Apparaît au scroll et remonte en douceur (`behavior: smooth`).
7. **Animations au scroll** : Apparition fluide des différentes sections de la page.
